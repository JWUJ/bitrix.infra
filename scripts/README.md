# Скрипты обслуживания инфраструктуры (Scripts)

Данный каталог содержит скрипты резервного копирования, синхронизации и обслуживания инфраструктуры проекта.

## Статус адаптации для hiik.ru

| Скрипт | Описание | Статус адаптации |
|---|---|---|
| `file-backup.sh` | Резервное копирование файлов веб-сайта в S3 | Настроен для hiik.ru (бывший `TODO-file-backup.sh`) |
| `mysql-dump.sh` | Дамп и бэкап базы данных MySQL | Настроен для hiik.ru (бывший `TODO-mysql-dump.sh`) |
| `disaster-recovery.sh` | Сценарий аварийного восстановления из бэкапов | Сохранён из upstream для накатывания улучшений автора |
| `renew-dev.sh` | Пересоздание dev-сайта из копии prod | Upstream скрипт |
| `fix-rights.sh` | Установка корректных прав (UID 1000/1001) | Готов к использованию |
| `optimise-images.sh` | Оптимизация изображений (jpeg, png, gif) | Upstream скрипт |
| `alter-robots-txt.sh` | Генерация/правка robots.txt | Кастомизирован под hiik.ru |
| `check-404.sh` | Проверка 404 ошибок | Кастомизирован под hiik.ru |
| `update-dns-token.sh` | Обновление токена DNS для Certbot | Upstream скрипт |
| `urls.py`, `setup.py` | Вспомогательные утилиты обработки URL | Upstream скрипт |
| `upstream-sync.ps1` | Проверка и синхронизация с paskal/bitrix.infra | Новый вспомогательный инструмент |
